# STM32Board



## 尺寸

PCB实测长约147mm，宽约41.4mm，不含工艺边。

厚度1.6mm，从板边断面看应为4层板。



## 接口和交互器件清单

### 正面

左侧板边24V直流输入，1x2P插拔式接线端子，弯插，P=5.08mm；正负极有丝印；

左侧板边电机编码器接口，2x4P线对板连接器，弯插，P=4.2mm；信号定义有丝印；



中央3位数码管；

按键两个（轻触开关，4.5x4.5mm）；



中央无线模块及接口x1；

模块为有人科技（USR）产品，厂家型号USR_WIFI232_A2，立创编号：C250562

根据说明书该模块功能为通过wifi透传RS232信号；

模块通过转接板连接板载连接器接口；1x7P 2.54mm Female Pin Header x1，1x3P 2.54mm Female Pin Header x1



右侧板边连接器

1x10P接线端子，插拔式，弯插，P=3.81mm，接口信号板上有丝印

| Pin Number | Signal | Silkscreen       |
| ---------- | ------ | ---------------- |
| 1          | GMS    | 终点传感器       |
| 2,5        | GND    |                  |
| 3,6        | V24    |                  |
| 4          | KMS    | 起点传感器       |
| 7,8        | O4,O3  | 磨砂玻璃左右密封 |
| 9,10       | O2,O1  | 上下密封         |



背面

1x5P 2.5mm或2.54mm线对板针座，信号定义未知，需测量；丝印标注J?2

保险丝座，参考立创编号C108518，LittleFuse SMD 5.0x9.7mm，电流大小未知；
