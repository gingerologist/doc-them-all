# 硬件设计文档



## 文档

本文档简述多极片项目的硬件设计。用户不必阅读此文档，硬件工程师如果想在现有设计上做修改应阅读本文档。

文档作者/硬件设计：马工（matianfu@gingerologist.com, 个人常用邮箱）



## 硬件设计说明

多极片硬件包含36个开关单元，每个开关可以把一个极片引脚置于3种状态之一：接信号（signal），接公共（com），或者不接（float）。

开关的实现使用光耦可控硅器件，每个开关单元里使用两颗，一颗用于把极片接信号，另一个用于把极片接com，总计使用了72个器件。



多极片硬件提供了两种控制方式，使用微处理器（mcu）控制，或者手动控制。板上有36个双刀三掷拨动开关。开关拨到中间位置（C位）时，微处理器控制生效，开关向上拨把该路极片接信号，向下拨则把该路极片接公共（信号和极片的输入输出连接器一侧为上）。无论是微处理器控制，还是手动控制，均有两颗LED显示开关当前状态，一颗显示当前极片接信号，另一颗显示当前极片接公共，如果两颗均不亮，则为未接，设计上不可能两颗同时亮。



产生光耦可控硅所需的电压，使用了数字晶体管以保证驱动能力。使用数字IO驱动芯片也是一种办法但应该注意其引脚的驱动能力，每个引脚应该可以输出5-10mA电流，保证光耦的发射侧光电二极管可以打开。



微处理器选用意法半导体STM32F103ZET6；主要是考虑其工业级可靠性，以及项目所需的较多的GPIO引脚。



硬件上还提供了10个按键，功能由软件定义；为使用方便，板载RESET开关（sw1），可快速重启微处理器。



电源设计上包含桶形连接器供电和USB Type C供电，后者有CC下拉电阻，可用任何Type C标准充电器。桶形连接器和Type C供电使用了专门的ORing芯片，实现任意一路均可供电且不会倒灌电流，或者一路供电的输出端放电电路给另一路供电放电。之后采用了一个3.3V LDO给微处理器供电。



板上还包含一个沁恒的CH340芯片，是USB to Serial Bridge芯片，使用单独芯片而不是MCU内置的USB的好处是：

1）避免MCU频繁上电掉电时的供电和通讯问题；也基本上可以避免类似问题导致的PC USB口损坏；

2）也保护了MCU的UART PIN；

3）CH340使用极其广泛，USB兼容性很好，避免软件协议栈问题；



开关，MCU Debug/烧录接口，均提供了ESD器件保护，防止因静电损毁器件。



Signal/COM和控制部分是隔离设计，该设计不是必须的，但可以减少不同设备的共地问题。



## 接口列表

| Designator | Description                                                  |
| ---------- | ------------------------------------------------------------ |
| J10        | 接信号发生器产生的信号，板上有丝印表明Signal和COM            |
| J1-J4      | 接4组，每组至多9个极片，板上有丝印标注9个极片的编号          |
| J9         | 标准JTAG口，实际仅使用SWD接口，而非JTAG接口；任何STLink V2/V3，Jlink调试器都可以直接连接，用杜邦线即可 |
| J8         | STM32的UART2，该接口也连接Ch340，主要供硬件调试时使用        |
| J5         | Type C供电和通讯接口，接电脑使用此接口                       |
| J6         | 2.5mm桶形连接器，不是2.1mm的，购买连接器时要注意             |



## 设计文件说明

使用KiCAD完成硬件设计，KiCAD是完全免费开源的EDA软件，支持Windows，Mac，Linux。



`hardware-desing.zip`打包了硬件设计的原始目录，里面有很多过期文件，但仍保留以便未来修改回溯方便。其中重要文件入下：

1. `multiads-evt1.kicad_pro`是项目文件，打开该文件可以打开KiCAD工程，包含原理（SCH）和布板（PCB）。
2. `multipads-evt1.kicad_sch`是原理图文件，可以单独打开但没有必要。
3. `multipads-evt1.kicad_pcb`是PCB文件，可以单独打开但没有必要。
4. 在`mfg3`目录下是生产文件，其中gerber，drill和placement文件按照嘉立创的加工格式要求输出，包括文件命名；`multipads-v3-BOM.xlsx`文件是BOM文件，符合立创贴片要求；该目录下提供`readme.txt`文件，是立创下单pcb加工时需要填写的内容，记录了所有的加工要求。



根目录下包含一个过期版本的原理图PDF文件，注意不要使用。应使用交付清单和打包文件里提供的最新版本。
